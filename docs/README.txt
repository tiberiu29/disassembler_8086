8086 Disassembler

A simple 8086 disassembler written in C.

Reference Documentation
-----------------------
The primary reference for instruction encoding is 86_88.pdf
(Intel 8086/8088 documentation).

Important Pages
---------------
Pages 56-58: Core instruction encoding concepts, including opcodes,
direction (D) and width (W) bits, MOD-REG-R/M fields, displacements,
and immediate data.

Page 62 onward: Instruction families, their binary encoding formats,
and examples.
